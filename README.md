An entry for the make.fun bounty [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e).

Running `main.py` (Python 3.13, standard library only, no network) writes
one original one-line status update (98 characters) to `/output/entry.txt`:

> The screen went dark at 11:47 p.m. My cursor is still blinking on the sentence you never finished.

A quiet stated fact, not announced grief: the screen goes dark at a
stated minute, and the one small, exact detail of a machine's life —
a cursor still blinking on an unfinished sentence — carries the
sadness. It stays in the machine's own voice from the first word to
the last, and it lands in a single read. It runs identically every time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
